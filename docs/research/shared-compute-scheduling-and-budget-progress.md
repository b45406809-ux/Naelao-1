## SC03 code checkpoint — `fa17d910` pushed, 2026-11-17 (retryable capacity admission)

DynamicSandbox capacity refusal is now distinct from an indeterminate execution. ToolSandboxDO persists `waiting_capacity` only for the exact pre-execution `container_concurrency_limit` error; a matching execution ID, signed scope and payload can atomically claim that receipt once. The response is HTTP 429 with `waiting_for_capacity`, `admission_id`, `execution_started:false` and `Retry-After`; the code runner retries only this structured response, preserving the immutable scope and request body. Existing authorization and budget checks run again on every retry, and no guest command starts or billing hold is created until capacity is acquired.

Evidence: the next local uncommitted delta adds the integrated queue/lease path. See the checkpoint immediately below. The previous `fa17d910` retry-only version did not itself queue waiters.

## SC03 code checkpoint — local, 2026-11-17 (fenced tenant queue and retry dispatch)

The shared ConcurrencyDO now owns one authenticated atomic global+tenant admission ledger. Waiting rows hold only tenant, holder, limits, expiry and state. They promote on release/expiry in oldest eligible order while skipping tenants already at their cap; every active lease has a monotonic fence and release requires the exact tenant/holder/token. DynamicSandbox uses this composite admission rather than taking global then tenant slots independently. A full wait leaves the matching ToolSandbox execution in `waiting_capacity`; the code runner retries that same scope/request; caller cancellation removes the waiter; no code or credentials are persisted. Existing tenant and Project/erasure/billing checks run again before launch.

Evidence: ConcurrencyDO, DynamicSandboxDO and code-runner capacity suites **61/61**, Agents typecheck and `git diff --check` pass locally. No rollout/deployment or live provider/DO acceptance. This is retry-driven dispatch, not a server-pushed wake: a bounded caller can still return waiting after five retries. There is no owner-facing queue/status/ETA API yet, fairness is tenant-only rather than tenant→Space→Project/member, and priority aging/workload weighting remain open. Preserve untracked `infra/scripts/__pycache__/`.
