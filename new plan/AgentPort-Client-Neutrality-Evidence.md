## Unimplemented or gated capabilities

- A live provider adapter must still be authorized and configured before AgentPort can create upstream accounts or execute provider actions. The API and docs return/reference this limitation; no live provider credentials or contracts were present in the repository session.
- No Singapore Singpass or other jurisdiction-specific identity provider is configured here. Principals remain unverified by default; AgentPort's generic principal issuer/reference fields are preserved, and providers can be integrated without making AgentPort itself a national identity system.
- AgentPort does not duplicate another host's employee directory. The host authenticates its employees and decides which organization principal owns each agent; AgentPort records both the owner principal and creator. Cross-platform employee verification requires an explicitly configured identity provider.
- The repository PR migration-order script remains blocked by a pre-existing duplicate `0092` prefix (`0092_marketplace_template_subscriptions.sql` and `0092_mcp_connector_provider_pin.sql`). Migration 0168 itself follows 0167 with no new gap; the duplicate is outside this change.
