## Conflicts and decisions

- The assistant's illustrative `$30/$100` and `$29/month` figures are examples only; implementation stores a customer-selected budget and never treats those values as product prices.
- “Optimized provider selection” was an assistant suggestion. `provider: "auto"` now selects a compatible registered provider deterministically, favoring an already active authorized account and then an available authorization path. It does not claim cost optimization without reliable provider pricing data.
- User-directed provider account independence overrides a simplistic shared Naelao master-account model. A managed account still needs authorized provider terms, a verifiable partnership, tenant/app budgets, and an execution adapter.
- `reportedCostUSD` is an app estimate and can be underreported by a hostile app owner. It is useful for app-side budgets and idempotent usage accounting, but is not a provider invoice or authoritative settlement.
- Channel/provider events belong in channel workups and Naelao runtime wakeups. AgentPort may retain event metadata and provider references, never conversation content.

## Remaining implementation boundary and external blockers

- No provider-specific provisioning/execution adapters, managed account pool, OAuth connector for service providers, Cloudflare Email address allocation/delivery, or verified provider settlement source is configured. The API records intent and authorization state; `managed` handles remain `adapter_unavailable`. Deploying or turning on managed service before provider contracts, account credentials, and verified adapters would be misleading and unsafe.
- Usage totals are app-reported estimates. Provider-confirmed usage/settlement is blocked on provider adapter integration.
- The generic AgentPort OAuth server/SDK supports third-party builders. Naelao's own OAuth account switch still needs a registered production client, callback, encrypted host token storage, and user-facing selector; no production client registration or host callback has been configured in this workspace.
- Live DNS/Worker health, migrations, provider OAuth, and app execution were not exercised from this workspace. CI/deployment credentials are not evidence of provider account approval.
