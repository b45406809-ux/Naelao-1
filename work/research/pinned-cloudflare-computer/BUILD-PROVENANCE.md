## Build record

The source was extracted from the hash-checked archive in `/tmp`. Dependencies were installed with
`npm ci --ignore-scripts --strict-ssl=true`; the required DOFS, RPC, computer and computerd
workspaces were built before the upstream `packages/computerd/scripts/build-bin.mjs` and
`build-docker.mjs` scripts ran. The binary builder compiled `fuse-napi` in Docker, downloaded
Node.js `v22.23.4` for the standalone executable, and built the local scratch image. The temporary
build-script adjustment only mounted the executor's proxy CA into that native-build container;
the upstream package source was unchanged. Two builds produced different binary hashes, so this
output is recorded as observed provenance, not claimed as bit-for-bit reproducible.
