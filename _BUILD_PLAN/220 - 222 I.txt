### 2. Space Assistant SDK vs. Project Agent SDK (RBAC by Construction)
The runtime automatically bounds `ctx` based on whether the agent is the **Space Assistant (CEO)** or a **Project Agent (Developer / Specialist)**:
```typescript
// workers/agents/src/script-engine/code-runner.ts
export function buildTierSdkContext(env: ScriptEngineEnv, scope: "SPACE_WIDE" | "PROJECT_BOUND") {
  // 1. Filesystem bound to the correct workspace prefix
  const fs = {
    read: (path: string, opts?: { offset?: number; limit?: number }) => 
      r2Workspace.operations.Read({ path, ...opts }, { env, run: null as any }),
    edit: (path: string, oldString: string, newString: string) => 
      r2Workspace.operations.Edit({ path, oldString, newString }, { env, run: null as any }),
    write: (path: string, content: string) => 
      r2Workspace.operations.Write({ path, content }, { env, run: null as any }),
    grep: (pattern: string, path?: string) => 
      r2Workspace.operations.Grep({ pattern, path }, { env, run: null as any }),
    glob: (pattern: string) => 
      r2Workspace.operations.Glob({ pattern }, { env, run: null as any }),
  };
  // 2. Project-level primitives (available to both Assistant and Project Agents)
  const project = env.projectId ? {
    id: env.projectId,
    getJournal: () => projectJournal.operations["project_journal.read"]({}, { env, run: null as any }),
    updateJournal: (status: string) => projectJournal.operations["project_journal.set_status"]({ status }, { env, run: null as any }),
    createTask: (title: string) => projectJournal.operations["project_journal.add_todo"]({ text: title }, { env, run: null as any }),
    listThreads: () => projectCoordination.operations["thread.list"]({ project_id: env.projectId }, { env, run: null as any }),
    postMessage: (threadId: string, text: string) => projectCoordination.operations["thread.send_message"]({ thread_id: threadId, message: text }, { env, run: null as any }),
  } : undefined;
  // 3. Space-level primitives (STRICTLY RESTRICTED to Space Assistant)
  const space = (scope === "SPACE_WIDE") ? {
    id: env.spaceId,
    createProject: (name: string, kind: string, templateId?: string) => 
      workspaceAdmin.operations["project.create_from_template"]({ templateId, name }, { env, run: null as any }),
    listProjects: () => workspaceAdmin.operations["project.list"]({}, { env, run: null as any }),
    getWalletBalance: () => businessWallet.operations["business_wallet.balance"]({}, { env, run: null as any }),
    sendNotification: (title: string, body: string) => notifications.operations["notify.email"]({ title, body }, { env, run: null as any }),
  } : undefined; // Project agents receive undefined for `ctx.space`!
  // 4. Zero-Leak Vault / MCP / Skills Bridge
  const mcp = {
    call: (server: string, tool: string, params: any) => mcpConnector.operations["mcp.call"]({ server, tool, params }, { env, run: null as any }),
    listTools: (server: string) => mcpConnector.operations["mcp.list_tools"]({ server }, { env, run: null as any })
  };
  const runSkill = (skillName: string, args: any) => env.codeRunner?.run({
    name: skillName,
    code: "", // Looked up from R2
    tier: 2,
    args,
    spaceId: env.spaceId,
    agentId: env.agentId,
    tenantId: env.tenantId,
    projectId: env.projectId
  });
  return { fs, project, space, mcp, runSkill };
}
```

### 3. The Zero-Leak Secret Injection Protocol
To ensure that API keys (Stripe secrets, GitHub tokens, database passwords) **never leak into the LLM context or conversation logs**:
1. Secrets live encrypted in `space_credentials` (AES-256-GCM).
2. The agent writes code referring only to the **credential name** (`ctx.vault.fetchWithAuth` or `ctx.mcp.call`).
3. The Cloudflare Worker injects the decrypted secret at the **edge network boundary** during the outbound fetch. The script code never holds `const key = "sk-live-..."`.
```typescript
// How the agent writes a script using vault credentials safely:
export async function run(args: any, ctx: any) {
  // The SDK automatically resolves 'STRIPE_API_KEY' inside the Worker runtime.
  // The secret is injected into the Authorization header at the network hop!
  const response = await ctx.vault.fetchWithAuth("https://api.stripe.com/v1/charges", {
    credentialName: "STRIPE_API_KEY",
    method: "POST",
    body: new URLSearchParams({ amount: args.amount, currency: "usd" })
  });
  return response.json();
}
```

### 5. Concrete Walkthrough: How the Agent Authors and Distills a Tool
#### Goal:
> *"Audit all markdown files in the project, check if they have a `# Title` header, insert one if missing, and log a task in the project journal."*
#### Turn 1: The AI Writes & Executes the Script in Tier 2 CodeMode
The AI calls `exec_isolate_codemode` with this self-authored TypeScript block:
```typescript
// Self-authored script by the agent:
const globResult = await ctx.fs.glob("**/*.md");
const modifiedFiles: string[] = [];
for (const file of globResult.files) {
  const readRes = await ctx.fs.read(file, { limit: 5 });
  if (!readRes.content.includes("# ")) {
    // Missing title header: patch using AST edit
    const titleName = file.split("/").pop()?.replace(".md", "").toUpperCase() || "DOCUMENT";
    await ctx.fs.edit(file, readRes.content.split("\n")[0] || "", `# ${titleName}\n\n${readRes.content}`);
    modifiedFiles.push(file);
  }
}
// Log completion to Project Journal
if (modifiedFiles.length > 0) {
  await ctx.project.createTask(`Auto-fixed missing titles in ${modifiedFiles.length} markdown files.`);
}
return {
  success: true,
  filesAudited: globResult.files.length,
  filesFixed: modifiedFiles
};
```
#### Execution & Compounding:
1. The script executes inside a V8 isolate in **12 milliseconds**.
2. All file modifications commit to the **Durable Object SQLite Virtual Filesystem** with zero intermediate token overhead.
3. The agent calls `script.distill("audit_and_fix_markdown_headers")` to save the script to its R2 Skill Library.
4. Next time, the agent executes the task in **1 turn for $0.0001** by calling `ctx.runSkill("audit_and_fix_markdown_headers")`.
