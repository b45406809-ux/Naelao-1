### 2. The 5 Core Configuration Modules
#### Module 1: The Phone Line Gate (Mandatory for Call Execution)
The project status remains **`AWAITING_TELEPHONY`** and will not start call listeners until a number is bound:
* **Option A (1-Click Purchase):** User clicks *"Get a Phone Number"*, picks an area code (`305 - Miami`), and Cloudflare’s `@cloudflare/voice-twilio` adapter provisions the number in 3 seconds.
* **Option B (BYO Twilio/Plivo):** User pastes their Twilio/Plivo SID & Auth token in project settings.
* **Option C (Call Forwarding):** User enters their existing clinic number and copies the SIP forwarding target.
#### Module 2: Voice Persona & Interruption Tuning (Vapi-Style)
Users configure the natural acoustics of the call:
* **TTS Provider & Voice ID:** Deepgram Aura, Cartesia Sonic, or ElevenLabs Flash running at Cloudflare's edge.
* **Barge-in / Interruption Sensitivity:** When a caller interrupts with *"Wait, let me check my card"*, the AI cuts its speech synthesis immediately within 50ms.
* **Greeting Message & First Turn Rules:** Whether the AI speaks first or waits for the caller to say *"Hello"*.
#### Module 3: Instant Calendar & Knowledge Base Linking
* **Shared State Booking:** Checking `[x] Enable Calendar Booking` automatically injects the `calendar.check_availability` and `calendar.book_slot` tools into the voice session.
* **Zero Hallucination Grounding:** When a caller asks *"Do you take Medicare?"*, Cloudflare AI Search fetches the clinic's insurance docs and injects the verified answer into the voice agent's sentence stream [1.1.2, 1.1.9].
#### Module 4: Outbound Campaigns & Scheduled Crons
The project allows scheduling automated outbound phone calls using **Tier 3 Dynamic Workflows & Crons**:
* **24-Hour Appointment Confirmation:** At 10:00 AM daily, a Cloudflare Workflow queries `SpaceDO.space_calendar` for tomorrow's appointments and calls each patient:
  > *"Hi John! This is Miami Dental calling to confirm your 3:00 PM appointment with Dr. Smith tomorrow. Can you make it?"*
* **Lead Follow-Up Calls:** Automatically triggers an outbound call 5 minutes after a lead submits a web form.
#### Module 5: Human Transfer & Emergency Escalation
* If a caller says *"This is a medical emergency"* or asks for a human 3 times, the agent executes `transfer_call({ destination: "+13059991234" })` and connects the line directly to Dr. Smith's cell phone.

### 4. Implementation: Outbound Cron Calling Workflow
When a scheduled cron fires for an outbound calling campaign, it runs via **Cloudflare Workflows (`OutboundCallWorkflow.ts`)**:
```typescript
// workers/agents/src/workflows/OutboundCallWorkflow.ts
import { WorkflowEntrypoint, WorkflowStep, WorkflowEvent } from "cloudflare:workers";
export class OutboundCallWorkflow extends WorkflowEntrypoint<Env, { spaceId: string; projectId: string }> {
  async run(event: WorkflowEvent<{ spaceId: string; projectId: string }>, step: WorkflowStep) {
    const { spaceId, projectId } = event.payload;
    // Step 1: Query SpaceDO calendar for tomorrow's appointments
    const appointmentsToConfirm = await step.do("fetch-tomorrow-schedule", async () => {
      const spaceDO = await spaceDoStub(this.env, spaceId);
      const res = await spaceDO.fetch(`http://internal/calendar/tomorrow-appointments?project_id=${projectId}`);
      return (await res.json()) as Array<{ id: string; clientName: string; clientPhone: string; time: string }>;
    });
    // Step 2: Dispatch outbound calls sequentially at edge
    for (const apt of appointmentsToConfirm) {
      await step.do(`call-${apt.id}`, async () => {
        // Dispatch call via @cloudflare/voice-twilio adapter
        return await this.env.VOICE_ADAPTER.makeOutboundCall({
          fromNumber: "+13055550199",
          toNumber: apt.clientPhone,
          agentSystemPrompt: `You are confirming an appointment for ${apt.clientName} tomorrow at ${apt.time}.`,
          greeting: `Hi ${apt.clientName}, this is Miami Dental calling to confirm your appointment tomorrow at ${apt.time}.`
        });
      });
      
      // 30-second pacing between calls
      await step.sleep(`pace-${apt.id}`, "30 seconds");
    }
  }
}
```

### Summary of What This Establishes:
1. **Vapi/Grok-Style Simplicity:** Complete visual and natural language control over greetings, system prompts, voices, interruption sensitivity, and business hours.
2. **Strict Telephony Guard:** The project explicitly requires an active phone line (1-click platform number or BYO Twilio) to receive/make calls.
3. **Automated Outbound Crons:** Workflows handle appointment reminder campaigns and lead follow-up calls automatically.
4. **Cross-Project Shared Calendar Integration:** Appointments booked over the phone commit atomically into **`SpaceDO` SQLite**, instantly visible to the doctor's document workstation and the founder's WhatsApp morning briefing.
