### 2. The User Never *Has* to Pick a Bot (Smart Auto-Routing)
Non-technical users shouldn't have to remember: *"Should I talk to @DevBot or @GrowthBot for this?"*
In your platform, users have **two ways to interact**:
#### A. The Simple Way (For Non-Technical Users — Zero `@mentions`):
The user simply types in the Project Chat:
> *"Can we change our homepage headline to 'Top Rated Dental Clinic in Miami' and send a tweet announcing our new Friday hours?"*
* **The Lead Agent handles delegation automatically:**
  * It detects the headline edit $\rightarrow$ silently routes the code patch to `@DevBot` [1.3.17].
  * It detects the tweet $\rightarrow$ silently routes the draft to `@GrowthBot` [1.3.17].
* The user gets one clean reply:
  > *"I've updated the homepage headline on your live preview and drafted the announcement tweet for your review."*
#### B. The Power-User Way (For Tech Teams & Agencies — Slack Style):
Power users who *want* fine-grained control can use `@mentions` directly:
> *"@DevBot please run the database migration."*
